# Provenance

Forked from https://github.com/slowsage/opentui-svelte at commit
`358902a288b6eb978758ef9b45ea7e1401fb0bfa` (initial upstream commit).

The initial implementation here incorporates the existing vscan adaptation of that source, including tree-fragment compilation, canonical property names, stable wrapper identity, keyboard subscriptions, and template snapshots. Those pre-existing changes are not claimed as new fixes by this fork.

Upstream declares MIT in package.json but does not include a standalone LICENSE file at this commit. Its source attribution is retained. A canonical copyright/license notice should be obtained before a registry release; this fork does not invent the original copyright holder's notice.

Package metadata uses the independent @maxwhitten scope rather than implying control of @opentui. No npm release has been made.
